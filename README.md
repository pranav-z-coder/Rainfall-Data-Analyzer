# Rainfall Data Analyzer

A Python-based application for analyzing monthly rainfall data using CSV files and visualizing rainfall trends.

## Features
- Calculate total, mean, maximum and minimum rainfall.
- Calculate standard deviation.
- Identify heavy rainfall months (above 200 mm).
- Visualize monthly rainfall trends.
- Compare rainfall with the average.
- Load different CSV files.
- Handle invalid and empty datasets.

## Technologies Used
- Python
- Pandas
- Matplotlib

## Installation

Install the required libraries:

```bash
pip install pandas matplotlib
```

## How to Run

```bash
python rainfall_analyzer.py
```

Follow the menu displayed in the terminal.

## Project Structure
- `rainfall_analyzer.py` – Main application.
- `rain.csv` – Default rainfall dataset.
- `Test cases/` – Test datasets.
- `empty.csv` – Empty CSV test file.
